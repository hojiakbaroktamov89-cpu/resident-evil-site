# Resident Evil Fan Website

A fully functional web application dedicated to the Resident Evil franchise, built using the Django framework.

## 🚀 Live Demo
You can visit the live website here: [https://resident-evil-site-production.up.railway.app](https://resident-evil-site-production.up.railway.app)

## 🛠️ Features & Tech Stack
* **Backend:** Python, Django Framework
* **Database:** MySQL
* **Frontend:** Custom Responsive UI styled with CSS
* Custom user interface inspired by the Umbrella Corporation theme.

## 📂 Project Structure
All the core backend and configuration files (`manage.py`, app modules, and settings) are located inside the `resite` folder.
